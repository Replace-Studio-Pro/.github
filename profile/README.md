Replace Studio Pro keeps one named board on the desk: the live pattern, the batch in front of you, and a short note the next operator can read. Extra tricks wait for their own title.

## How Replace Studio Pro Sits

Replace Studio Pro does not replace a silent Explorer trick, the unlabeled pattern dump, or a batch on files you do not own. It sits beside them as a named edit desk for one job: which text replace is live, which file batch still matches owned files, and what the next operator should read.

Extra tricks wait for their own title instead of crowding the live batch. A Replace Studio Pro edit desk stays on files you own.

A first visit should be one short text replace on files you own, then the same Replace Studio Pro edit desk the next day. That is enough to see if the named text batch holds.

## Open Order

1. Open the last Replace Studio Pro edit desk, not a new empty file batch.
2. Read the owned files and the last handoff.
3. Finish one visible text replace inside Replace Studio Pro on files you own.
4. Write what changed, then close with fewer Explorer tricks than you found.
5. If the batch feels crowded, drop anything that belongs to a different Replace Studio Pro job.
6. Confirm Replace Studio Pro owned files still sit on files you own, then leave the edit desk title on the board.

## After a Week

A week in Replace Studio Pro is not a larger pile of Explorer tricks. It is the same title, a shorter live pattern, and a note that still makes sense before the next file batch. Take finished replaces off the live set so the next visit starts on the edit desk that is still open.

Other programs stay where they are. Replace Studio Pro only keeps the path back: desk name, owned files, text replace, handoff.

Leave Replace Studio Pro with a quieter edit desk than the one you opened. The next visit should start on that named text batch, not on a silent trick.

## Field Note

Replace Studio Pro is easier to trust when the edit desk stays smaller than the Explorer-trick pile it came from. Name the file batch, keep the live pattern, finish one visible text replace, and write what changed.

The same loop fits a review pass, a close-out, or a shared PC. Open the last Replace Studio Pro desk and continue. Do not run a file batch on files you do not own.
